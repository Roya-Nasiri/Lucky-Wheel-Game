# 🎡 Lucky Wheel Game

An interactive and fun spinning wheel game built with pure HTML, CSS, and JavaScript.

Spin the wheel, test your luck, and win random rewards with smooth animations and a clean UI design.

## ✨ Features

* 🎯 Random prize generator
* 🔄 Smooth wheel rotation animation
* 🎉 Dynamic win / lose messages
* 🔁 Reset and replay functionality
* 📱 Responsive design
* ⚡ Built with Vanilla JavaScript

## 🛠 Technologies

* HTML5
* CSS3
* JavaScript

## 🚀 How to Play

1. Click the **Spin** button
2. Wait for the wheel to stop
3. See your reward
4. Reset and play again

## 📌 Project Purpose

This project was created to practice:

* DOM manipulation
* JavaScript logic
* CSS animations
* Interactive UI design
